# fevnem.github.io — Rakib Hasan

Personal bio/portfolio site, served via GitHub Pages.

- `biodata.html` — homepage (hero, PFP, skills, CTA)
- `projects.html` — projects listing
- `index.html` — root redirect → `biodata.html` (GitHub Pages needs an `index.html` at the root)
- `styles.css` / `script.js` — theme + interactions

Plain HTML/CSS/JS — no build step. Root serves `biodata.html` through the redirect.
