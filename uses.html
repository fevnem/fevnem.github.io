What I build with

No affiliate links, no logo wall. One line each on why a thing earns its place.

Languages

  • Go — services and small binaries. One file to run, no runtime to install, and the standard library is usually enough.
  • JavaScript, as ES modules — for things that must run in a browser without a build step. No bundler, ever.
  • Python — data work and throwaway analysis. It stays throwaway on purpose.

Instruments

  • WebGL2, hand-written — for explaining things that need a picture you can turn. Shaders written by hand beat a scene-graph library for one-off work.
  • Plain canvas 2D — when the thing is a chart, not a world.
  • Node, only as a test driver — headless Chromium over raw CDP, zero dependencies, aimed at the page I just wrote.

Hardware

  • A headless Linux box — most of what I make is built and verified on a server with no screen, then looked at in a browser when it is done.
  • Whatever keyboard is nearest — this is not that kind of page.

Services

  • GitHub — the code lives there, and this site is served from it as plain files.
  • Nothing analytics-shaped — no trackers, no cookies, no third-party fonts. The page you are reading made zero requests off this domain.
